Panduan Penggunaan SIPEKA DF

Pedoman operasional bagi Asisten Afdeling, Krani Cek Sawit, dan Mandor Panen untuk memverifikasi kesesuaian data Digital Farming di perkebunan kelapa sawit.

  • Pastikan Anda mengunduh dokumen laporan resmi dari sistem Digital Farming.
  • Laporan Mandor (PB24A): Formulir rekapitulasi hasil pengumpulan buah per pemanen di setiap blok.
  • Laporan KCS (PB24B): Formulir pengangkutan buah dari TPH ke Pabrik Kelapa Sawit (PKS).
  • Format harus berupa PDF digital resmi (bukan foto kamera atau hasil pindai buram).

  1. Masuk ke menu Pemeriksaan Data.
  2. Pilih file Laporan Mandor (PB24A) pada slot pertama.
  3. Pilih file Laporan KCS (PB24B) pada slot kedua.
  4. Tekan tombol hijau Bandingkan Data.
  5. Hasil perbandingan langsung disajikan secara terperinci per baris dan per blok.

  • Cocok: Angka jumlah janjang Mandor dan KCS persis sama (Selisih = 0).
  • Berbeda: Terdapat selisih angka antara laporan Mandor dan KCS.
  • Hanya Ada di Mandor: Buah dicatat dipanen namun belum dicatat diangkut oleh KCS (kemungkinan restan TPH).
  • Hanya Ada di KCS: KCS mencatat pemuatan tetapi Mandor tidak mencatat pemanen terkait.

Total janjang yang sama tidak menjamin data sudah benar! Sebagai contoh:

  • Blok 136: Mandor = 72, KCS = 75 (Selisih: +3)
  • Blok 137: Mandor = 80, KCS = 77 (Selisih: -3)
  • Total Keseluruhan: Mandor = 152, KCS = 152 (Selisih Total = 0).

Meskipun total akhir sama, distribusi per blok salah. SIPEKA DF secara otomatis memunculkan peringatan merah jika kondisi ini terdeteksi.

Gunakan tombol Ekspor Excel (CSV) untuk membagikan temuan selisih kepada Mandor dan Krani guna kroscek fisik di TPH (Tempat Pengumpulan Hasil).

Tentang SIPEKA DF

Sistem Pemeriksa Kesalahan Data Digital Farming — Versi 1.0.0

Tujuan Aplikasi

Mengotomatisasi proses rekonsiliasi laporan operasional panen kelapa sawit antara Mandor Panen (PB24A) dan Krani Cek Sawit / Krani Transport (PB24B). Menghilangkan pemeriksaan manual berbasis kertas yang memakan waktu lama dan rentan luput.

Arsitektur & Keamanan

  • 100% Pemrosesan Lokal: Tidak ada ketergantungan koneksi internet dan tidak ada data yang dikirim ke cloud luar.
  • Privasi Data: File PDF temporer dibersihkan secara otomatis setelah ekstraksi selesai.
  • Standar Excel: Ekspor CSV menyertakan UTF-8 BOM agar angka dan teks terbuka rapi di Microsoft Excel.
